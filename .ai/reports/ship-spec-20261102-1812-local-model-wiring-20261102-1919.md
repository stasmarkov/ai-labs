## Confirmed review findings

Near-duplicate findings from different review angles are merged below.

### Major

- `tests/Feature/OllamaProviderTest.php:44`: the AC-1, AC-2 and AC-3 tests assert defaults that come from env, but `phpunit.xml` pins only `AI_PROVIDER`, `AI_FAKE_TOKENS` and `AI_FAKE_TOKEN_DELAY_MS`. Any `.env` override, such as `AI_THINK=true`, `AI_MAX_TOKENS=1200` or `OLLAMA_MODEL`, turns the suite red, which breaks MNC-2. Fix: pin `AI_MAX_TOKENS`, `AI_TIMEOUT`, `AI_THINK`, `AI_MODEL`, `OLLAMA_URL`, `OLLAMA_MODEL`, `OLLAMA_KEEP_ALIVE` and `OLLAMA_NUM_CTX` in `phpunit.xml`, or set the config explicitly in the tests.
- `app/Ai/CarDescriptionAgent.php:36`: `providerOptions()` looks up request options by driver name (the SDK passes `$provider->driver()`), while `maxTokens()` and `timeout()` read the `ai.default` entry. A second Ollama entry such as `ollama-big`, or an explicit `provider:` argument, gets settings from two different entries. If no entry is named `ollama`, no request options are sent, so thinking is on by default. The spec's check that the driver is `ollama` is also missing. Fix: resolve all three settings from the same entry.
- `routes/catalog.php:12` and `config/ai.php:79`: `/listings/{id}/describe` has no throttle, no concurrency cap and no auth. Every call now runs real GPU inference and holds a PHP worker for up to 120 s. Four parallel requests take all four frankenphp-octane workers and stall `/up` and `/listings`, and every call adds an `ai_runs` row. Fix: add a named `RateLimiter` (`throttle:describe`), think about a concurrency lock that returns 429 or 503, and lower `AI_TIMEOUT`.

### Minor

- `config/ai.php:82`: `(string) env('OLLAMA_KEEP_ALIVE')` sends `-1` or `3600` as a JSON string, Ollama rejects it with 400, and every describe request fails. Fix: cast numeric values to int.
- `bench/sse.sh:42`: in `--real` mode the `distinct_ms=` label prints a different metric (changes from the previous event, not distinct timestamps), and `docs/learning-guide.md:297` describes it wrongly. Fix: rename the field (for example `changes=`) and correct the guide wording.
- `bench/sse.sh:72`: `*) ID=...` takes typos such as `--rael` as the listing id, which gives a 404 and exit 2. Fix: reject unknown `--*` flags and extra positional arguments with the usage message.
- `app/Ai/CarDescriptionAgent.php:53`: `timeout()` hard-codes the SDK's 60 s default, and the MNC-1 test pins that copied number. Fix: move the default into config, either per entry or as one shared value.
