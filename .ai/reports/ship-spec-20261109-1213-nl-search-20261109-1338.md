## Confirmed review findings

### Major

- `resources/js/ai/Pages/Lab/NlSearch.vue:171`: `answer.value !== target` compares a reactive proxy with the raw object, so `loadRun()` never fetches. It also writes to the raw object, so nothing re-renders. Fix: compare with `toRaw(answer.value)`, or take `const target = answer.value` after the assignment and change it through the proxy. Two reviewers found this independently.
- `app/Ai/ListingFilterAgent.php:41`: the fuel enum has no `null`, so constrained decoding has to return a fuel, and searches like "show me everything" get silently narrowed. Fix:
  - add `null` to the enum values;
  - update `tests/Unit/ListingFilterAgentTest.php:20`;
  - re-run `nl:eval` and update BENCHMARKS.md and guide section 24.
- `app/Ai/ListingFilterAgent.php:17`: the agent inherits the provider's 120 s timeout and only a per-IP throttle protects it. A slow Ollama can tie up all 8 PHP workers. Fix: give the agent its own 10-15 s timeout and/or a concurrency lock.
- `app/Repositories/AiRunLatencyRepository.php:9`: this repository has no interface or binding, and its query duplicates `EloquentRagEvalRepository::timings()`. Fix: reuse `RagEvalRepositoryInterface::timings()`, or move the lookup onto `AiRunRepositoryInterface`.
- `app/Services/NlSearchService.php:122`: the mapping from validated data to `ListingFilter` is copied from `ListListingsRequest::toFilter()`, so the two paths can drift. Fix: move it into one `ListingFilter::fromValidated()` and call it from both.

### Minor

- `app/Services/NlSearchService.php:119`: validation lets booleans and whole floats through (for example `max_price: true` becomes a 1-euro cap). Fix: use strict integer checks for the NL input, or cast after validation.
- `app/Rules/ListingFilterRules.php:18`: make, model and city have no `ValidUtf8Text`, so a NUL byte from the model reaches PostgreSQL and comes back as a 500. Fix: add `new ValidUtf8Text` to those three rules.
- `app/Services/LabOverviewService.php:69`: the card title is "Natural-language search" and it sits after Chat, but Q10 says "NL search" after "Semantic search". Fix: rename and move it to index 2 (and update `AiLabNlSearchTest`), or amend Q10.
- `resources/js/ai/Pages/Lab/NlSearch.vue:234`: the length alert uses `query.length` (UTF-16 units, untrimmed), but the button and server count trimmed code points. Fix: use `[...query.trim()].length` in both places.
- `app/Services/NlSearchService.php:108`: `$validator->fails()` is called twice, so every rule runs twice. Fix: store the result once and reuse it.
