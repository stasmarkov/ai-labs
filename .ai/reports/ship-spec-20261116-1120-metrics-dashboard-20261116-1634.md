## Confirmed review findings

### Major

- F1 `.ddev/metrics/grafana/dashboards/frankenphp.json:61`: the RPS and status-code panels count each request three times in frankenphp-worker mode. **Fixed**
- F2 `bench/metrics-snapshot.sh:97`: p95 is capped at 10 s by Caddy's default histogram buckets, so SSE cells report a false p95. **Fixed**
- F4 `docs/learning-guide.md:540`: worker and Octane saturation is invisible, because queue_depth counts only regular requests and busy_threads includes idle worker threads. **Fixed**
- F9 `.ddev/docker-compose.metrics.yaml:38`: Grafana keeps the default admin/admin account, which is reachable over the API. Hiding the login form does not disable login. **Fixed**
- F10 `.ddev/servers/frankenphp-worker/web-build/Caddyfile.frankenphp:12`: worker and Octane record HTTP metrics on every request, even when the stack is off, and no control cell measures that cost. **Fixed**
- F14 `.ddev/metrics/prometheus.yml:9`: the ai-lab site name is hardcoded in container hostnames instead of using service names or `DDEV_SITENAME`. **Fixed**

### Minor

- F3 `bench/metrics-snapshot.sh:97`: the snapshot p95 mixes health-probe, warm-up and load requests. **Remaining**
- F5 `bench/metrics-matrix.sh:105`: `--quick` always refuses to run without `--force`. **Fixed**
- F6 `bench/metrics-matrix.sh:74`: keep-alive can launch concurrent `ddev start` runs that are not stopped. **Remaining**
- F7 `bench/metrics-snapshot.sh:99`: scrape coverage counts `up` samples, which exist even when the target is down. **Fixed**
- F8 `tests/Fixtures/metrics/frankenphp-worker.txt:1`: the fixtures are older than the per_host change, so they do not match the live label set. **Remaining**
- F11 `.ddev/metrics/grafana/dashboards/frankenphp.json:9`: the 1s refresh is below Grafana's 5s minimum, and the screenshot URL leaves auto-refresh on. **Fixed**
- F12 `bench/metrics-snapshot.sh:124`: each snapshot starts a fresh Playwright container and runs `npm install` over the network. **Remaining**
- F13 `bench/metrics-matrix.sh:69`: keep-alive polls Docker during measured windows, and its `ddev metrics on` fallback can outlive `keepalive_stop`. **Remaining**
- F15 `tests/Feature/MetricsGatesTest.php:12`: `MetricsGatesTest` duplicates assertions from `MetricsStackConfigTest`. **Fixed**
- F16 `tests/Feature/MetricsGatesTest.php:61`: a test asserts the content of the spec's `tasks.md` checklist, not behavior. **Remaining**
- F17 `.ddev/commands/host/metrics:51`: `off` repeats the container names instead of using the variables it already defines. **Fixed**
- F18 `bench/metrics-snapshot.sh:43`: a no-op sed substitution in the `--help` handler. **Fixed**
- F19 `tests/Feature/BenchMetricsSnapshotTest.php:45`: unused branches in the test stubs. **Fixed**
- F20 `.ddev/servers/frankenphp/web-build/Caddyfile.frankenphp:15`: per_host metrics are on in all three Caddyfiles with no consumer (the label is always `host="_other"`). **Remaining**
