### Major

- F1, `app/Lessons/LessonRepository.php:50`: "Go deeper" links to `#failures` and `#recipes` open the wrong guide tab. **Fixed.**

- F18, `app/Lessons/LessonRepository.php:50`: The lesson "deeper" tab vocabulary duplicates the guide page's tab keys and drifts from them, so `#failures` and `#recipes` links never open a tab. **Fixed.**

- F20, `app/Services/GuidePageService.php:121`: `GuidePageService` uses an optional constructor dependency with a container service-locator fallback. **Fixed.**

- F2, `app/Lessons/LessonRepository.php:556`: `kpis` is required on every step except step 1 (the flag is inverted). **Fixed.**

- F5, `resources/lessons/running-models/one-model-many-users.php:199`: KPI trend colours mark scenario switches as better or worse, and the summary mixes two models. **Remaining.**

- F7, `app/Lessons/LessonRepository.php:409`: The authoring guide calls the callout optional, but the validator requires it. **Fixed.**
- F8, `resources/lessons/running-models/one-model-many-users.php:216`: Step 6 draws its conclusion from two unrelated experiments. **Remaining.**
- F9, `app/Lessons/LessonService.php:42`: Lesson files missing from `course.php` can still be played by URL. **Remaining.**
- F10, `resources/js/ai/composables/useLessonProgress.ts:27`: Malformed progress in `localStorage` crashes the lesson page. **Remaining.**
- F11, `app/Lessons/LessonRepository.php:373`: Numeric-looking node or edge ids are rejected in state patches. **Fixed.**
- F12 (security), `app/Lessons/LessonService.php:42`: Unlisted (draft) lesson files are publicly routable, because course membership is never enforced on `/ai/learn/{module}/{lesson}`. **Remaining.**
- F13 (security), `resources/js/ai/composables/useLessonProgress.ts:27`: Lesson progress read from `localStorage` is trusted without shape validation, so a bad record throws in `markViewed`. **Remaining.**
- F16 (performance), `app/Services/GuidePageService.php:121`: The guide page builds full lessons only to show their titles, and does it outside the guide render cache. **Remaining.**
- F17 (performance), `resources/js/ai/components/lesson/SceneCanvas.vue:147`: The rAF loop keeps running while paused, off-screen or with no packets. **Remaining.**
- F21 (design), `app/Guides/GuideRepository.php:276`: Guides and Lessons depend on each other, and `GuideRepository` hard-codes the lesson file layout to avoid the cycle. **Remaining.**
- F22 (design), `app/Lessons/LessonNumbers.php:23`: `LessonNumbers` re-implements the `bench/results` JSON reader that `GuideFacts` already provides, with a different path syntax. **Remaining.**
- F23 (design), `resources/js/ai/composables/useLessonProgress.ts:50`: Dead code: `useLessonProgress` exposes `doneCount`, which nothing uses. **Fixed.**
- F24 (design), `app/Lessons/LessonRepository.php:71`: Two production methods are called only by tests: `LessonRepository::files()` and `LessonNumbers::filesRead()`. **Remaining.**
