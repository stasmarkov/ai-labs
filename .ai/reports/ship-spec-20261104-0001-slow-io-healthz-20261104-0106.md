## Confirmed review findings

### Major

- `bench/k6-sse.js:29`: two checks per stream, so `slow-load.sh:282-283` counts a non-200 stream twice and an incomplete one as half. Fix: use one combined check, or a `Rate` metric `stream_failed` recorded once per iteration, and parse that (gap 15).
- `bench/slow-load.sh:238`: the probe runs `oha -c 2 -q 5` without `--latency-correction`. Once `/healthz` takes more than 400 ms the probe sends far fewer than 5 rps (coordinated omission). Fix: pass `--latency-correction` and/or set `PROBE_CONNECTIONS` to at least 50 (5 qps x 10 s timeout). Also correct the header at line 8.
- `bench/slow-load.sh:224`: health p50/p95/p99 leave out timed-out probes, so p95 looks better exactly when the server is saturated. Fix: count each timeout as `PROBE_TIMEOUT` in the percentiles, or flag a cell as "p95 censored" when more than 5 % of probes time out.
- `routes/catalog.php:17`: `listings.slow` is public, unthrottled and not gated by environment, and each call holds a worker for 0.3 to 3 s, so anyone can drain the pool with concurrent requests. Fix: gate it with `EnsureDebugRoutes` (the bench already sets `DEBUG_ROUTES=true`) and/or add a named per-IP rate limiter.

### Minor

- `bench/slow-load.sh:263`: an all-timeout probe gets a made-up 10000 ms p50/p95/p99, and that value flows into the median, the spread and the table. Fix: carry `no_response` into `median` and `flagged`, and print a marker instead of a number (gap 16).
- `bench/k6-sse.js:23`: id rotation restarts at 1 in every k6 process, so the warm-up pre-warms the exact ids each repeat reads. Fix: pass a per-phase/repeat id offset through the environment.
- `app/Http/Responses/JsonErrorRenderer.php:23-24`: `listings.slow` gets JSON errors by route name only, so `/listings/0/slow`, `/listings/abc/slow` and a 405 render the HTML error page. Fix: add `|| $request->is('listings/*/slow')`.
- `bench/slow-load.sh:324`: the median takes the upper middle value for an even repeat count. The spread is 0 whenever the median is 0. `BENCH_REPEATS=0` hangs `jq -s`. Fix: average the two middle values, compute the spread against the max when the median is 0, and reject `BENCH_REPEATS < 1`.
- `.ddev/vinstub/server.mjs:16`: an uncaught `URIError` from `decodeURIComponent` kills the stub, and `restart: "no"` keeps it down. Fix: wrap the decode in try/catch and answer 400, and/or set `restart: unless-stopped`.
- `app/Contracts/VinReportServiceInterface.php:11`: no test fakes this interface, and it breaks the repository-only Contracts convention. Fix: drop it and inject the concrete `VinReportService`.
- `bench/k6-sse.js:6`: the unused `VUS` default of `'64'` contradicts the 30-user design. Fix: default to 30, or fail when `VUS` is missing.
- `bench/concurrency.sh:48`: `usage()` does not mention `autoscale`. Fix: add it and merge the two usage functions.
