## Summary

## Acceptance

**Did the original scenario resolve end to end? No.** The learner journey works, but several acceptance criteria are not met.

Hops that work: `/` and `/ai` link each capability to its live page and its guide; `/ai/guides` and all 11 keys return 200, while `/ai/guides/nope` and `..%2F.env` return 404; "Run it" prefills `/ai/chat?q=...` and does not run on its own; during a chat stream one step is highlighted (▶, `aria-current=step`), and all steps are marked done at the end; "Open the full guide" leads to `/ai/guides/chat`. NFR-1 passes (p95 between 35 and 56 ms on FrankenPHP), as do NFR-2 (roving tab focus, no overflow at 390 px), NFR-3, and MNC-1, MNC-3, MNC-4, MNC-5 and MNC-6.

Broken hops and unmet criteria:

1. **AC-1 (fails):** `guide.numbers[*]` sends `file` and `path` (for example `chat-stop/2026-11-03/frankenphp.json`). The `/ai/guides/chat` props also contain `bench/results/docs-cache/2026-11-03/run/calibration.json`, from a comment in the `config/ai.php` snippet. `NoReferencesInUiTest` misses both: it blanks every `file` key at any depth, and its regex leaves out `bench/`. Task 18.
2. **AC-5 (fails, found by reading the code):** `NlSearch.vue:172` sets the panel to `done` for invalid or refused outcomes, and `activeStep()` returns done before it checks `FAILURE_EVENTS`. A validation failure therefore shows ✓ instead of ✗ "(failed)". Task 17.
3. **AC-8 / clarity answer 11 (fails):** `LabOverviewService::capabilities()` hard-codes summaries that differ from the guide files, and the navigation puts Guides last instead of second. Task 20.
4. **Spec shape:** numbers have no `unit`. Task 19.
5. **MNC-2:** only partly checked. Stop and the cache badge were not exercised, and task 16 is not recorded.

Accepted deviations from the spec text, with the criteria still met: the Implementation tab is built from the works steps that have snippets; anchors use `guide:start`/`guide:end` markers; symbol ranges leave out the docblock; each step has one `event`.

**E2E regression test:** none written. The stack declares no browser e2e harness, so no AC ids are traced to an e2e test. Browser acceptance was checked by hand with Playwright, and nothing was saved as a test.

## Confirmed review findings

### Major

- `app/Services/GuidePageService.php:55` (also :61): `howItWorks()` runs the full `GuideRenderer::render()` on each of the five live pages. That includes reflection, `filemtime` on snippet sources, and reading bench JSON (about 110 KB on Chat; NL search decodes `run.json` four times). It then keeps only the step title, html and event. A renamed method or a missing bench file returns a 500 from the live pages, which breaks MNC-2 and the rule "fails a test, never the page". Fix: add a steps-only path (`GuideRepository::steps($key)`) that resolves no numbers, facts or snippets.
- `app/Services/GuidePageService.php:75`: the snippet code is sent twice, once in `works` and once in `implementation` (about 24 KB each on docs, out of a 56 KB page). Fix: strip `snippet` from `works` in `show()`.
- `resources/js/ai/Pages/Lab/NlSearch.vue:172`: an invalid or refused outcome sets the panel state to `done`, so the failure never shows. Fix: set `error` for every outcome that is not ok, or check `FAILURE_EVENTS` before the `done` early return in `useGuideSteps.ts:43`. Task 17.
- `app/Services/LabOverviewService.php:65`: summaries are hard-coded and drift from `resources/guides/*.php`, and `guideKey` is a redundant copy of `key`. Fix: read `summary` and `guideKey` from `GuideRepository`. Task 20.
- `app/Services/GuidePageService.php:13`: `kind` is hard-coded in `CAPABILITY_KEYS` and repeated in `GuideContentTest` and `LabOverviewService`. No guide file declares `kind`, and nothing enforces the per-kind minimums. Fix: declare `kind` in each guide file and validate the per-kind required sections in `GuideRepository::build()`.
- `resources/guides/guards.php:87`: the "ignore its rules" experiment sends the learner to `ai.docs`, which has no input guard, so the stored answer is wrong. Fix: point it at `ai.chat`.
- `app/Guides/GuideFacts.php:52`: the providers facts leave out `default_for_embeddings`. The guide shows fake-stream while semantic and docs embed with ollama/bge-m3, and `providers.php:15-17` says "nothing else names a provider", which is false. Fix: add the embeddings provider and model to the facts, and correct that sentence.

### Minor

- `app/Guides/GuideRenderer.php:31`: numbers keep `file`, `path` and `pending`; experiments keep `answer.numbers`. None of these are used, and the bench paths leak into the props. In `tests/Feature/NoReferencesInUiTest.php:16`, the exemption is wider than `snippets[*].file`. Fix: send only `label` and `value`, and narrow the test exemption. Task 18.
- `app/Guides/GuideRenderer.php:48`: the cache key has no renderer version, so old payloads survive a change to `build()`. That can leak keys that were removed, or cause an undefined-index 500. Fix: add a `VERSION` constant to the key.
- `app/Guides/GuideRenderer.php:29`: `rememberForever` with content-hashed keys leaves old entries behind (database or Redis with noeviction). Fix: use a finite TTL, or a stable per-guide key that stores its fingerprint.
- `app/Guides/SnippetResolver.php:54`: Reflection ranges start at the `function`/`class` line and drop the docblock and attributes. Fix: extend the start upward over `getDocComment()` and the attribute lines.
- `resources/js/ai/Pages/Lab/NlSearch.vue:125`: a refusal is mapped to `validation_failed` (step 4) instead of `refused` on the guard step (step 2). Fix: emit `refused` and map step 2 to it in `nl-search.php`.
- `resources/guides/chat.php:18`: on a cache hit `sources` arrives before `cache_hit`, and the step index only moves forward, so the cache step is never highlighted. Fix: order the step mapping to match the wire order, or let a mapped event move the index back.
- `resources/js/ai/composables/useGuideSteps.ts:43`: after Stop, the ▶ marker stays as if the run were still going. A chat refusal marks every step ✓. Fix: treat `stopped` as an end state, and mark as done only the steps that were reached.
- `app/Http/Controllers/ShowLabPhotosController.php:19`: "Read the plan" opens How it works. Fix: append `#plan`.
- `resources/js/ai/Pages/Lab/Guide.vue:160`: the Implementation tab shows no explanation, only the title and the code. Fix: render `step.html` next to `LabCode`.
- `resources/js/ai/Pages/Lab/Guide.vue:193`: `v-bind="experiment"` leaks `page="ai.chat"` and `params="[object Object]"` onto the `<article>`. Fix: drop `page` and `params` on the server, or set `inheritAttrs: false`.
- `app/Services/LabOverviewService.php:93`: Guides comes last in the navigation. Fix: put it right after Overview. Task 20.
