- **All other criteria pass:** AC-1-3, AC-5-7, AC-9, AC-12, AC-13, MNC-1 (`.ddev/config.yaml` unchanged after two real switches), MNC-2 and MNC-3.

## Confirmed review findings

Duplicate findings from different review dimensions are merged.

### Major

- `bench/parity.sh:36`: `capture` truncates the committed snapshot. It writes the header and then aborts silently if curl fails (reproduced: exit 7, only the header left). It also leaks the temp body file. **Fix:** write to a mktemp file and `mv` it into place only after all 7 requests succeed. Add `-S`, check for `http_code` 000, and print an error.
- `.ddev/apache/apache-charset.conf:3`: this custom Apache header rewrite makes the content-type columns match by changing the server under test. It breaks the spec's out-of-scope and ask-first rules, isn't mentioned in the docs, and adds mod_headers work that will skew benchmarks. **Fix:** get approval and record it as a decision, or delete the file, re-capture, and accept the content-type diff.
- `.ddev/commands/host/server:52`: there is no mapping from server name to overlay content, so the spec's extension point doesn't exist. Generic-type servers (FrankenPHP, Octane, OLS) can't be added as list entries, and `--current` couldn't tell them apart. **Fix:** use a map from name to overlay body and store the logical name in the overlay, for example as a comment marker.
- `tests/Feature/BenchmarksDocTest.php:22`: the test reads the developer's gitignored `.env`. It fails whenever someone follows the documented `DEBUG_ROUTES=true` step, it checks nothing in CI, and it is mislabelled AC-12. **Fix:** delete the test and make this a manual-plan step.

### Minor

- `.ddev/commands/host/server:54`: after a failed `ddev restart`, the script restores the old overlay but not the running project. The `already active` check then blocks recovery and can mislabel snapshots. **Fix:** run `ddev restart` again after restoring, or tell the user to. Alternatively, take the active label from the server that actually answers.
- `bench/versions.sh:12`: when the site is unreachable, the script exits silently with curl's exit code. Every non-200 response gets the DEBUG_ROUTES hint. **Fix:** check curl's exit status separately, and print different messages for connection failures and 404s.
- `bench/versions.sh:12`: TLS verification is always off (`-k`). **Fix:** make it opt-in through `PARITY_INSECURE=1`, as parity.sh does (task 13).
- `bench/versions.sh:8`: the script reads a generic `BASE_URL` instead of `PARITY_BASE_URL`, which can produce mixed rows. Lines 4 and 14 say `config:clear`, and the active-server lookup differs from parity.sh. **Fix:** use `PARITY_BASE_URL`, `optimize:clear`, and the same lookup as parity.sh.
- `bench/parity.sh:41`: render-time masking applies to every body, not only `/up`, and decision 6 is still pending. **Fix:** limit the sed to `/up` and get decision 6 confirmed.
- `app/Http/Controllers/DebugRuntimeController.php:23`: the controller reads `$_SERVER` directly, so tests can't exercise the string branch. **Fix:** inject `Request` and use `$request->server('SERVER_SOFTWARE')`, plus a test with `withServerVariables()`.
- `tests/Feature/BenchScriptsTest.php:141`: the test name says compare ignores content-type parameters, which it doesn't, and the test really covers capture. **Fix:** rename it to describe the capture-side masking, and relabel it AC-8 / decision 6.
- `BENCHMARKS.md:14`: heading case is mixed, and the file says "media type" where the snapshots store the full content type. It also doesn't mention the `/up` masking or the Apache charset override. **Fix:** make the headings consistent, correct the description, and document both caveats.
