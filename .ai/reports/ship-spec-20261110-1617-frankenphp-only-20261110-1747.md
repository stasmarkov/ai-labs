## Confirmed review findings

### Major

1. `.ddev/commands/host/server:70`: switching away from an OpenLiteSpeed overlay leaves `.ddev/docker-compose.openlitespeed.yaml` behind. Its build context `./servers/openlitespeed` is deleted, so `ddev restart` fails, the switch aborts back to the old overlay, and `ddev setup` loops. This breaks clarity 5 and MNC-1. Reported three times (correctness, design, and security as minor). **Fix:** in the switch path, delete `.ddev/docker-compose.<name>.yaml` for each name in `REMOVED_SERVERS`, and add a test that creates that file (gap 15).
2. `bench/export-load-matrix.sh:41`: the offload cells on frankenphp-worker and frankenphp-octane actually measure stream-fallback. Those modes set no `EXPORTS_SENDFILE_INTERCEPT`, and `export-load.sh` never checks `X-Export-Mode`, so the stream results are saved as `offload-*.json`. Reported three times (correctness, performance, design). **Fix:** skip offload on the worker and Octane modes, or make `export-load.sh` refuse or label the run when the response says `stream-fallback`.

### Minor

3. `bench/compression.sh:53`, and also `early-hints.sh:33`, `http3.sh:74`, `lcp.mjs:258`, `export-load.sh:114`, `slow-load.sh:126`, `leaks.sh:115` and `chat-stop.sh:58/181`: these scripts use the now multi-word `--current` output as a label or file name. **Fix:** add one shared guard in `servers.sh` that refuses both the not-set-up and removed states, and call it from every script that reads `--current`.
4. `bench/chat-stop.sh:37`: `--modes frankenphp,nginx-fpm` measures frankenphp first, then exits 1. **Fix:** source `lib/servers.sh` and validate the whole list up front, exiting 2 (gap 16).
5. `.ddev/commands/host/server:178`: run with no arguments on a removed-server overlay, the command prints `Active: openlitespeed` with no removal hint. **Fix:** reuse the removed-server branch from `--current`.
6. `.ddev/commands/host/server:71`: leftover files from removed servers are neither cleaned up nor gitignored any more, so a stale sidecar can be committed with `git add .`, and a leftover `nginx-site.conf.bench-orig` is never restored. **Fix:** delete the known removed-server files on switch or setup, or keep the gitignore lines until that cleanup exists.
7. `app/Enums/OffloadHeader.php:13`: the X-Accel and X-LiteSpeed offload paths, `config/exports.php:56,76` and the nginx `/_protected_exports/` location are still live, and only their comments were reworded. **Fix:** remove them, or record in the spec that they stay on purpose as an app-level feature.
8. `tests/Feature/FrankenphpOnlyTest.php:37`: the guard allowlists whole files (CLAUDE.md and 16 tests). **Fix:** match per line, or build the names in the tests from `REMOVED_SERVERS` (gap 17).
9. `resources/guides/describe.php:42`: this guide still tells learners to set Apache `flushpackets`. **Fix:** reword it the same way as streaming.php, as history ("measured earlier on PHP-FPM").
