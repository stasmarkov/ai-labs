## Confirmed review findings

Duplicate findings from different review dimensions are merged.

### Major

- `bench/lib/netem.sh:59` (and `:141`): netem drops whole GSO/TSO/GRO skbs, while `tc` counts `Sent` per segment and `dropped` per skb. The loss therefore comes in bursts, ingress reads low (1.24 % and 1.39 % at 2 %), and h2 and h3 may see different loss shapes. Fix: run `ethtool -K <dev> gso off tso off gro off` on the client eth0, ifb0 and the web interface (or count in bytes), and document the limitation.
- `bench/lib/netem.sh:98`: the RTT probe downloads the full 43 KB `/` page 20 times, and the counters are never reset, so the drop-rate check mostly measures probe traffic. Fix: probe `/up` connect-only or with HEAD, and take a counter baseline after verify.
- `bench/lcp.mjs:347`: netem mode always goes direct but records `path: options.path`, so the plan and the result disagree. Fix: reject `--path router` with `--net netem`, or force `direct` and drop the `--path`/`--path-reason` requirement there.
- `.ai/specs/spec-20261105-1109-http3/manual-test.md:44`: the step 3 command cannot run. Fix: use `--variant $p-loss$l --path direct --path-reason "..."` and add a test like the one for step 2.

### Minor

- `bench/http3.sh:126`: no `alpn_h2` field (AC-1). Fix: emit `alpn_h2` (keep `h2_alpn` per Q6) and assert it in `BenchHttp3Test` and `BenchCommittedRunsTest`.
- `bench/http3.sh:110` (security): raw bodies are copied into the committed results directory, and `H2_STATUS` is never checked (`:82`). Fix: require h2 status 200, and write the bodies to `$WORK` or `bench/results/raw/`.
- `bench/lcp.mjs:378` (security): an unsanitized `--variant` can escape the results tree or overwrite `frankenphp.json`. Fix: validate it against `^[a-z0-9-]+$` and use a distinct prefix or subdirectory for netem results.
- `bench/lib/netem.sh:167`: the drop window is fixed at 1 to 3.5 % whatever `--loss` is. Fix: derive the window from `NETEM_LOSS`, or have lcp.mjs accept only 0 and 2.
- `bench/lcp.mjs:250`: SIGINT or SIGTERM leaves the `lcp-netem-<pid>` container running. Fix: add SIGINT and SIGTERM handlers that call `process.exit`.
- `bench/lcp.mjs:274`: a `page.goto` throw aborts the whole variant, so the retry budget goes unused. Fix: catch per-run errors in `measureInside` and return them as invalid samples.
- `bench/lcp.mjs:198`: `NETEM_THROTTLE` duplicates the netem.sh defaults. Fix: build `throttle` from the returned `netProfile`.
- `bench/http3.sh:42`: the Q7 switch to frankenphp with a trap that restores nginx-fpm is not implemented. Fix: add a wrapper using `bench/lib/env-switch.sh` like `bench/lcp.sh`, or record it as a deviation in `tasks.md`.
- `.ai/specs/spec-20261105-1109-http3/manual-test.md:35`: step 2 expects a drop rate that no command in the step reads. Fix: add `bench/lib/netem.sh drops netem-client` after real traffic.
- `BENCHMARKS.md:868`: says loss was "measured per run". Fix: say "per variant, probe traffic included".
- `BENCHMARKS.md:866` (also `:873` and `docs/learning-guide.md:1021`): "most runs lose nothing" is unsupported. Fix: say that losses happened but were mostly recovered cheaply.
- `BENCHMARKS.md:873`: the h3 cold-load saving relies on `--origin-to-force-quic-on`. Fix: add a caveat that a real first visit goes over h2, or measure a warm second navigation.
