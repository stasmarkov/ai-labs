## Confirmed review findings

### Major

- **F1** `.ddev/commands/host/dev-watch:44`: the dev-watch Octane overlay sorts last with `override_config` and silently overrides bench daemon overlays applied later. **fixed**
- **F2** `app/Http/Middleware/ConnectXdebugOnTrigger.php:32`: an Xdebug session opened in a worker is never closed, so later requests without the trigger also stop at breakpoints. **fixed**
- **F3** `config/octane.php:186`: the Octane and worker watch lists dropped `bootstrap/` and `composer.lock`, so edits to `bootstrap/app.php` and providers never trigger a reload. **fixed**
- **F6** `app/Http/Middleware/ConnectXdebugOnTrigger.php:47`: the trigger middleware ignores `xdebug.trigger_value`, so the trigger secret no longer protects anything (security). **fixed**
- **F9** `app/Http/Middleware/ConnectXdebugOnTrigger.php:32`: a triggered Xdebug session stays attached to the worker thread for every later request (performance). **fixed**
- **F10** `tests/Feature/BenchReloadLatencyTest.php:81`: the test takes about 33 s because each run waits out the real never-trial cap. **fixed**

### Minor

- **F4** `app/Http/Middleware/ConnectXdebugOnTrigger.php:45`: the middleware ignores the standard `XDEBUG_SESSION` / `XDEBUG_SESSION_START` triggers. **fixed**
- **F5** `BENCHMARKS.md:1599`: the conclusion "most of the wait is the file sync" is not supported by the data. **fixed**
- **F7** `app/Http/Middleware/ConnectXdebugOnTrigger.php:32`: in worker mode a triggered connection persists, so later untriggered requests from other users are debugged too (security). **remaining**
- **F8** `bench/xdebug-check.php:14`: the DBGp check listener binds to all interfaces on the host. **fixed**
- **F11** `bench/reload-latency.sh:174`: the Mutagen probe runs `ddev exec` in a background loop during each timed trial. Its numbers are inflated and it adds load during the timing. **remaining**
- **F12** `bench/reload-latency.sh:196`: `restart_ms` includes the `ddev exec` and Artisan boot overhead but is reported as the worker restart cost. **fixed**
- **F13** `app/Http/Middleware/ConnectXdebugOnTrigger.php:31`: in classic mode, a triggered request with no IDE listening tries to connect twice. **fixed**
- **F14** `.ddev/commands/host/server:161`: the dev-watch overlay path is hardcoded in several places, and `bench_overlays` now returns a non-bench overlay. **remaining**
- **F15** `app/Http/Controllers/DebugReloadProbeController.php:19`: a redundant `debug_routes` guard in the new controller, which the route-group middleware already enforces. **fixed**

The remaining findings are all minor (F7, F11, F14) and do not block SHIP on their own.
