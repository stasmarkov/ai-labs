## Confirmed review findings

### Major
- `resources/js/ai/Pages/Lab/Docs.vue:121`: every docs search sends three requests and embeds the query twice (vector and hybrid). This doubles Ollama load, skews the embed timings the page reports, and uses 3 throttle units per search. Fix: add one endpoint that embeds once and returns all three lists.
- `app/Repositories/EloquentAiRunRepository.php:37`: `recent()` orders by `created_at DESC, id DESC` with no index, which forces a full scan and sort on every /ai load, and it selects `*`. Fix: add a `(created_at DESC, id DESC)` index or order by `id`, and select only the summary columns.
- `app/Services/LabOverviewService.php:33`: capability and nav URLs are literal strings, repeated in `LabLayout.vue:13-20` and in the placeholder controllers. Fix: build them with `route('ai.*', [], false)` in one server-side source and share it.

### Minor
- `app/Repositories/EloquentAiRunRepository.php:49` (security): the public `GET /ai/runs/{id}` returns the raw provider `error_message`, which includes internal Ollama URLs. Fix: return a generic message per `error_class` and keep the raw text in logs.
- `resources/js/ai/Pages/Lab/Describe.vue:128`: failed runs never show their logged `ai_runs` row, because the lookup only starts on 'done'. Fix: also call `loadRun` on 'error' when an invocationId was received.
- `resources/js/ai/composables/useEventStream.ts:105`: tok/s counts the first token inside its own interval and measures to finish time. Fix: use `(tokens - 1) / (lastTokenAt - firstTokenAt)`.
- `resources/js/ai/components/LabSimilarityBar.vue:23`: the printed similarity is clamped to [0,1], so negative cosine values show as 0.0000. Fix: clamp only the bar width.
- `resources/js/ai/Pages/Lab/Semantic.vue:42` (also `Docs.vue:68`): the length check uses untrimmed UTF-16 length, while the server uses trimmed `mb_strlen`. Fix: compare `[...query.value.trim()].length`.
- `resources/js/ai/Pages/Lab/Describe.vue:54`: `/^\d+$/` accepts '0', '0123' and 19-digit ids, which the route rejects. Fix: match the route constraint `[1-9][0-9]{0,17}`.
- `resources/js/ai/Pages/Lab/Overview.vue:55`: relative time shows "60 minutes ago" and "24 hours ago". Fix: round before choosing the unit.
- `resources/views/ai/app.blade.php:7`: the current page chunk is not preloaded. Fix: add `resources/js/ai/Pages/{$page['component']}.vue` to `@vite`.
